# DIT-P06 – CRM Lead Management Automation (Team T06)
DIT Internship 2026 · TASK 07

**Team:** T06 · **Members:** Madhumitha, Kanmani

Automates the lead-handling cycle: **validate → de-duplicate → score & grade → assign to sales reps → set follow-up SLA → report**.
All data is **synthetic**; no real personal data is used.

## Setup
```
python -m venv venv && venv\Scripts\activate      # Windows  (Linux/Mac: source venv/bin/activate)
pip install -r requirements.txt
```
## Run
```

python main.py --as-of 2026-11-02          # runs pipeline (omit --as-of to use today)
python -m unittest -v                      # runs 10 test cases
```

## Business rules (see config.py)
- **Required**: lead_id, name, email, phone (valid 10-digit Indian mobile), source, region, created_date.
- **Duplicates**: same email → earliest record kept.
- **Score (max 100)**: source 25 + budget 25 + company size 15 + engagement 15 (`min(15, visits*2 + emails_opened)`) + purchase timeline 20.
- **Grade**: Hot ≥ 70, Warm 40–69, Cold < 40.
- **Assignment**: by region, round-robin; Hot → Senior rep, Warm/Cold → Junior reps; closed leads (Converted/Lost) not assigned.
- **SLA** (first response for status `New`): Hot 1 day, Warm 3 days, Cold 7 days from created_date; later = breached.
